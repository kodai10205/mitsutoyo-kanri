# MITSUTOYO管理（人員配置・日程・出面・日報）

スマホやパソコンにインストールして使える、空調設備工事向けの管理アプリです。
このフォルダのファイルを GitHub に置くと、URL を開くだけで使えます。

## ファイル一覧（すべて、同じ場所に置いてください）

| ファイル | 役割 |
|---|---|
| index.html | アプリ本体 |
| config.js | 共有（Firebase）の設定。ここだけ書き換えます |
| sync.js | 共有とファイル保存の接続部分 |
| sw.js | オフラインでも開けるようにする仕組み |
| manifest.webmanifest | インストール用の情報（名前・アイコン） |
| icon-192.png / icon-512.png / icon-maskable-512.png / apple-touch-icon.png / favicon.svg | アプリのアイコン |

## 手順1　GitHub で公開する

1. GitHub にログインし、右上の「＋」→「New repository」を選びます。
2. 名前を付けます（例：`mitsutoyo-kanri`）。公開設定は「Public」にします（無料の GitHub Pages は Public が必要です）。
3. 作成後の画面で「uploading an existing file」を押し、このフォルダのファイルをすべてアップロードして「Commit changes」を押します。
   - フォルダごとではなく、ファイルをそのまま（フォルダを作らずに）置いてください。
4. リポジトリの「Settings」→「Pages」を開き、「Source」を「Deploy from a branch」、Branch を「main」「/ (root)」にして「Save」を押します。
5. 数分後、`https://（あなたのGitHub名）.github.io/（リポジトリ名）/` で開けるようになります。これがアプリのURLです。

※ Public のリポジトリでは、アプリのファイル（プログラム）が誰にでも見えます。現場・作業員・日報のデータは、GitHub には置かれません（手順3で作る Firebase に保存され、ログインした人だけが見られます）。

## 手順2　スマホにインストールする

- **iPhone**：Safari で上のURLを開き、共有ボタン →「ホーム画面に追加」。
- **Android**：Chrome で開き、メニュー（︙）→「アプリをインストール」または「ホーム画面に追加」。
- **パソコン（Chrome / Edge）**：アドレスバーの右にあるインストールのアイコンを押します。

## 手順3　他の端末・他の人と共有する（Firebase）

この手順を行わない場合は、データは各端末の中だけに保存されます（共有されません）。

1. https://console.firebase.google.com を開き、Google アカウントでログインして「プロジェクトを追加」。名前は自由です（Google アナリティクスはオフで構いません）。
2. 左メニューの「構築」→「Firestore Database」→「データベースを作成」。ロケーションは `asia-northeast1`（東京）を選び、「本番環境モード」で開始します。
3. Firestore の「ルール」タブを開き、中身を次の内容に置き換えて「公開」を押します。

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /teams/{team}/{document=**} {
      allow read, write: if request.auth != null;
    }
  }
}
```

4. 左メニューの「構築」→「Authentication」→「始める」→「ログイン方法」で「メール / パスワード」を有効にします。
5. 「Authentication」→「ユーザー」→「ユーザーを追加」で、使う人のメールアドレスとパスワードを登録します（人数分）。
6. 「Authentication」→「設定」→「承認済みドメイン」に、`（あなたのGitHub名）.github.io` を追加します。
7. 「プロジェクトの設定」（歯車）→「全般」→「マイアプリ」で「ウェブ」（`</>`）を選んでアプリを登録します。表示される `firebaseConfig` の中身（apiKey など6項目）を控えます。
8. GitHub のリポジトリで `config.js` を開き、鉛筆アイコン（編集）で、控えた値を `apiKey: ""` などの引用符の中に貼り付け、「Commit changes」を押します。

以上で、アプリを開くとログイン画面が出ます。登録したメールアドレスとパスワードでログインすると、全員が同じデータを見て、編集できます。

※ `apiKey` などは、Firebase の仕様上、公開されても問題ありません（データはログインとルールで守られます）。その代わり、ルールと、ユーザー登録は必ず手順どおりに設定してください。

## 手順4　今までのデータを引き継ぐ

1. これまでの Claude 上のページを開き、「作業員」タブの一番下にある「データを書き出す」でファイルを保存します。
2. 新しいアプリ（手順3まで終えたもの）にログインし、「作業員」タブの一番下で「データを読み込む」を押し、そのファイルを選びます。

## 更新のしかた

`index.html` などを GitHub 上で差し替えて「Commit changes」を押すと、数分後に反映されます。アプリを一度閉じて、開き直してください。

## 困ったとき

- ログイン画面が出ない・共有されない：`config.js` の値が空でないか、承認済みドメインに追加したかを確認してください。
- 「保存できませんでした」と出る：Firestore のルール（手順3の3）と、ログインできているかを確認してください。
- 印刷画面が開かないとき：日報のプレビューで「PDFで保存」を使い、保存したPDFを開いて、B5・倍率100％で印刷してください。
